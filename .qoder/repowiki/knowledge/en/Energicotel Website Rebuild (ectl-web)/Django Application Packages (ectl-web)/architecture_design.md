Each subdirectory under `apps/` is a standalone Django app following the standard layout (`__init__.py`, `apps.py`, `models.py`, `views.py`, `admin.py`, `migrations/`). The `core` app provides the home page via a `TemplateView` and a `context_processors.py`; other apps (`contact`, `gallery`, `news`, `team`, `units`) are feature domains with their own models, views, and admin registrations. All model and admin files currently contain only docstring placeholders pointing to CLAUDE.md phase sections — actual implementations are deferred to Phase 3+. Dependency direction is one-way: each app depends on Django and is wired into the project's root `INSTALLED_APPS` by its `apps.py` configuration; there is no cross-app import between these packages at this stage.
