- Each live page has a matching triple: an HTML snapshot in `html/`, plus three screenshot variants (`_desktop.png`, `_tablet.png`, `_mobile.png`) under `screenshots/`, all sharing the same page slug as the filename stem.
- `tokens.json` mirrors the page set under a top-level `pages` object where each key corresponds to a page slug and contains `url`, `meta`, `elements`, and histogram arrays (`top_text_colors`, `top_backgrounds`, `top_font_sizes`).
- Computed style objects inside `tokens.json.elements` use a fixed schema of keys (`tag`, `classes`, `text_sample`, `color`, `background_color`, `background_image`, `font_family`, `font_size`, `font_weight`, `line_height`, `letter_spacing`, `text_transform`, `border_radius`, `border`, `padding`, `box_shadow`, `transition`, `width`, `height`), with absent values represented as `null`.
- Frequency histograms in `tokens.json` are stored as `[value, count]` pairs sorted by descending count, and the same ordered lists are reproduced verbatim in `tokens_summary.md`.
