Dev setup: `python -m venv .venv && pip install -r requirements/dev.txt && copy .env.example .env && python manage.py migrate && python manage.py tailwind build`. Run with `python manage.py runserver`; compile CSS with `python manage.py tailwind watch` in a separate terminal. Production sets `DJANGO_SETTINGS_MODULE=config.settings.prod` plus `SECRET_KEY`, `ALLOWED_HOSTS`, `DATABASE_URL`, `CSRF_TRUSTED_ORIGINS`, then runs `collectstatic` and `gunicorn config.wsgi:application` behind Nginx + Cloudflare.
